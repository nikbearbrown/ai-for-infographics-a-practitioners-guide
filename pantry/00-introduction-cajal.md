## Fig I.1 — The Labor Split: Design Intelligence vs. Delegated Execution
- **Concept:** The book's thesis as a division of labor — the design-intelligence layer (variable selection, encoding choice, hierarchy, annotation placement, layout) requires human judgment; the execution layer (valid SVG markup) is delegated to the AI code generator.
- **Type:** Two-column split diagram, human column left / machine column right, a single shared canvas with a dividing rule and a down-arrow into the deliverable.
- **Shows:** Five design decisions stacked in the human column against the one thing the machine reliably supplies (syntactically valid markup) in the machine column; the disclosure as the falsification instrument below.
- **Scope:** Intro sections "The thesis" and "A note on what irreducibly human means." Does not restate the prose; gives the reader the labor split at a glance.
- **Red-accent element:** The human design-intelligence column header — the layer the machine can't reach.
