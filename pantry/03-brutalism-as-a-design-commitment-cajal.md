## Fig 3.1 — The Blur Test: What Survives Honest Hierarchy
- **Concept:** The blur test as an operational check on honest hierarchy. Blur the figure until detail dissolves; in an honest hierarchy exactly three things survive in order of prominence — headline claim, main visual, primary annotation. If a gridline or decoration survives as loudly as the data, the hierarchy lies.
- **Type:** Before/after — left: a sharp figure with all marks; right: the same figure heavily blurred (rendered with feGaussianBlur) showing only the surviving weights.
- **Shows:** Left: headline + bars + annotation + faint gridlines + a decorative flourish, all sharp. Right: blurred — only headline, the dominant bar, and the one annotation remain as distinct weights; gridlines and flourish vanish. A pass/checklist column names the three survivors.
- **Scope:** Chapter 3 "The blur test: a practical instrument." Lets the reader see the test rather than only read it.
- **Red-accent element:** The surviving main-visual bar in the blurred panel — the primary encoding that must dominate the first pre-attentive glance.
