# CAJAL — Chapter 8: Color Systems and Typography for Infographics

## Figure 8.1 — Seven tokens by role + the luminance ladder
- **Concept:** Color is a typed system, not decoration; each token has a role, and grayscale-stable luminance carries quantity while hue carries category.
- **Type:** Swatch table + luminance ladder.
- **Shows:** The seven tokens with their roles; ochre flagged "STRUCTURE — NEVER DATA"; a luminance ladder proving the tokens stay distinguishable in grayscale.
- **Scope:** The palette logic; one accent.
- **Red accent:** The red token row — the single data accent — shown sitting at mid-dark luminance, surviving grayscale.

## Figure 8.2 — Typography is hierarchy, not style
- **Concept:** Three font families assigned by role build a visible reading hierarchy.
- **Type:** Specimen / hierarchy stack.
- **Shows:** EB Garamond (display), Inter (body/labels), JetBrains Mono (axis digits) at descending sizes/weights, with the one luminance step down for supporting text.
- **Scope:** The three-font stack by role.
- **Red accent:** The one title/headline element set in the editorial display voice (single emphasis).
