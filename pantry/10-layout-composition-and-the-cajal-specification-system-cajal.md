# CAJAL — Chapter 10: Layout, Composition, and the CAJAL Specification System

## Figure 10.1 — The CAJAL pipeline: vague brief → SCOPE → DESIGN.md
- **Concept:** A vague brief becomes a defensible figure only by passing through the SCOPE specification (S/C/O/P/E) and being operationalized as DESIGN.md before any SVG exists.
- **Type:** Left-to-right pipeline with the five SCOPE blocks stacked in the middle.
- **Shows:** Vague brief → SCOPE (Specification, Content, Organization, Presentation, EXCLUSIONS) → DESIGN.md → (downstream) SVG. SCOPE blocks shown in dependency order; Exclusions emphasized as the highest-leverage block.
- **Scope:** One concept moving through the intake; one accent.
- **Red accent:** The EXCLUSIONS block — the highest-leverage parameter, the part that says "not this."
