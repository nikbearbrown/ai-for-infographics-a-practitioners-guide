# CAJAL — Chapter 13 figures

## Fig 13-01 — Same brief, twice: specification-less vs. specification-driven
- **Concept:** The same prompt, same model, same 90 seconds yields wildly different results depending on whether governing files are in context. Run one: 11 checklist violations. Run two: zero corrections. The gap is the lesson.
- **Type:** Before/after fork diagram (one brief branching two ways with a counted gap).
- **Shows:** A single brief splitting into two branches — specification-less (bare prompt → 11 violations, two of them perceptual lies) vs. specification-driven (CLAUDE.md + DESIGN.md + SCOPE → 0 corrections). The violation count is the payload.
- **Scope:** Single panel; brief at top, two branches descending, tally at each branch foot.
- **Red accent (ONE):** The spec-driven branch's "0 corrections / DEFENSIBLE" result — the one path the book endorses.

## Fig 13-02 — The semantic layer scaffold (painter's order = editorial naming)
- **Concept:** Named layers created up front in painter's order make rendering order and editorial naming the same act. Document order IS z-order (Ch7), so ci-band-before-line fixes occlusion by construction, and each layer arrives in Illustrator with a human-readable name.
- **Type:** Stacked-layer diagram (painter's-order stack with semantic labels).
- **Shows:** Five named layers stacked bottom-to-top (background, gridlines, ci-band, estimate-line, annotation); arrow showing paint order = append order; the same stack mirrored as the Illustrator Layers panel.
- **Scope:** Single panel; SVG document-order stack on left, equivalent Illustrator panel on right.
- **Red accent (ONE):** The annotation/accent layer at the top of the painter's stack (the single accent that earns the top paint position).
